# StudyFlow — Student Study Planner

A responsive student study planner built with HTML, CSS, and vanilla JavaScript.

## Features
- Add tasks with subject, priority, and due date
- Mark tasks complete, filter tasks, and delete tasks
- Dashboard progress and focus-time statistics
- 25-minute Pomodoro-style focus timer
- Dark mode
- Responsive mobile navigation
- Tasks and preferences saved in browser localStorage

## Run locally
1. Download and extract `student_study_planner_project.zip`.
2. Open `index.html` in your browser.
3. For the best development experience, use VS Code with the Live Server extension.

## Publish on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait a minute and open the URL shown in the Pages section.

## Customize
- Change the title and page content in `index.html`.
- Change colors and layout in `style.css` (`:root` variables are near the top).
- Change planner behavior in `script.js`.

This project is front-end only. Tasks are stored in the current browser, not in a shared database or user account.
